This repository contains practical assignments and lab exercises completed as part of the **Full Stack Web Development Lab** course at college.

The repository covers frontend development, Node.js fundamentals, Express.js, REST APIs, and frontend-backend integration using React.

## 📚 Repository Contents

**Concepts Covered:**
- HTML page structure
- CSS styling and layouts
- JavaScript functionality
- Product listing and product details
- Shopping cart interface
- Checkout page design

### 2. Lab Sheet 4 — Node.js Fundamentals
Practical exercises covering the fundamentals of Node.js.

**Topics Covered:**
- Node.js modules
- File system operations

- Path and OS modules
- Events and EventEmitter
- HTTP server creation
- Streams

### 3. Lab Sheet 5 — Express.js
Exercises focused on creating web servers and APIs using Express.js.

**Topics Covered:**
- Express server setup
- Routing and HTTP methods
- Route parameters and query parameters
- Request body handling
- Middleware
- REST API development
- Static file serving
- Error handling and 404 responses

### 4. Lab Sheet 6 — Full-Stack Integration
Practical exercises demonstrating communication between a frontend client and a backend API.

**Topics Covered:**
- Node.js and Express.js backend
- REST API development
- CRUD operations

- React components and hooks
- API requests and responses
- CORS configuration
- Loading and error states
- API key-based request authentication

## ⚙️ How to Run the Practicals

### Prerequisites
Install the following:
- Node.js
- npm
- Visual Studio Code
- Postman (for API testing, if required)

Verify the installation:

```bash
node -v
npm -v
```

### Lab Sheet 4 — Node.js

Navigate to the `nodejs-lab4` directory and run the required JavaScript file:

```bash
cd nodejs-lab4
node app1.js
```

Replace `app1.js` with the filename of the practical you want to execute.

### Lab Sheet 5 — Express.js

```bash
cd "Lab sheet 5"
npm install
npm run dev
```

### Lab Sheet 6 — Backend Server

```bash
cd LabSheet6_Complete/Server
npm install
npm run dev
```

Configure the required environment variables in a `.env` file before running the server.

### Lab Sheet 6 — React Client

Open another terminal:

```bash
cd LabSheet6_Complete/client-react
npm install
npm run dev
```

Follow the local URL displayed by Vite in the terminal.
